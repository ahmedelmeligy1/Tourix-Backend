# 🚀 Tourix Backend

The backend service for **Tourix**, an AI-powered smart tourism platform that transforms traditional sightseeing into an interactive and gamified experience.

This repository contains the RESTful Web API responsible for business logic, authentication, trip management, AI verification workflows, reward systems, and communication with the mobile application.

---

## 🌟 Overview

The Tourix Backend provides all server-side functionality required by the mobile application, including:

- User Authentication & Authorization
- Tourist Trip Management
- Smart Route Management
- Quest & Challenge System
- Visit Verification
- AI Image Verification Integration
- Rewards & Gamification
- Chat APIs
- Permit Requests
- Notifications
- Reviews
- Admin Dashboard APIs
